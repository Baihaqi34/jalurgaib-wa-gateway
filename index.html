Integrasi Cepat di Berbagai Bahasa

Gunakan API Key dari dashboard Anda untuk memanggil API kami dari Laravel, Node.js, atau Python. 

use Illuminate\Support\Facades\Http;

$response = Http::withHeaders([
    'X-API-Key' => 'JG_GAIB_YOUR_API_KEY',
    'Accept'    => 'application/json',
])->post('http://localhost:8000/api/messages/send', [
    'device_id' => 'dev_primary',

]);

if ($response->successful()) {
    $data = $response->json();

TANYA JAWAB

Frequently Asked Questions

Hal penting seputar operasional layanan JalurGaib.wa

Apakah saya perlu install software atau server sendiri di komputer saya? +
Tidak perlu sama sekali! Layanan kami beroperasi 100% sebagai Managed Cloud SaaS. Seluruh infrastruktur server, antrean pesan, dan mesin koneksi sudah kami kelola sepenuhnya di cloud. Anda cukup mendaftar, scan QR untuk menautkan nomor, dan langsung mengirimkan pesan melalui REST API.
Metode pembayaran apa saja yang didukung? +
Kami mendukung pembayaran otomatis instan via QRIS (BCA, GoPay, OVO, Dana, ShopeePay, LinkAja, seluruh mobile banking) serta Virtual Account Bank (BRI, Mandiri, BNI, Permata, dll) melalui integrasi resmi Kasera Pay. Pembayaran terkonfirmasi otomatis dalam hitungan detik.
Apakah HP saya harus selalu terhubung ke charger & internet? +
Tidak! Berkat fitur WhatsApp Multi-Device resmi, setelah scan QR sekali dari dashboard kami, sesi Anda tersimpan aman di server cloud. HP Anda bisa dalam kondisi mati atau kehabisan baterai, server akan tetap online dan siap memproses pengiriman pesan.
Bagaimana cara sistem mencegah nomor terkena banned? +
Server kami menerapkan Adaptive Human Jitter Delay (jeda acak bertahap per pesan) serta buffer antrean cerdas. Pola pengiriman ini meniru ritme pengetikan manusia normal secara natural sehingga tidak memicu radar deteksi otomatis sistem WhatsApp.
