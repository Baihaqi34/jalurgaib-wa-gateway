Cara Integrasi Client ke Gateway

Aplikasi Anda (PHP, Node.js, Python, Mobile App, dsb.) bertindak sebagai Client yang cukup menembak endpoint Laravel Gateway dengan header X-API-Key.

// 1. Contoh Request Kirim Pesan (cURL)
curl -X POST "http://localhost:8000/api/messages/send" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: wag_xxxxxxxx..." \
  -d '{
    "device_id": "dev_GadV4eCt8wJF",
    "to": "6281234567890",
    "message": "Halo dari aplikasi Client!",
    "min_delay": 1000,
    "max_delay": 3000
  }'
// 2. Response dari Gateway
{
  "success": true,
  "message": "Message queued for delivery",
  "data": {
    "message_id": "msg_68a9f...",
    "status": "queued"
  }
}
